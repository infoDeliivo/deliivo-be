Deliivo Website – Baltic SEO Requirements
1. Multilingual URL Structure (Required)
Website should use language-based URLs.
Structure:
https://deliivo.com/en/
https://deliivo.com/ee/
https://deliivo.com/lv/
https://deliivo.com/lt/
https://deliivo.com/ru/
Language dropdown should update URL accordingly.
Examples:
/en/
/ee/
/lv/
/lt/
/ru/
URL prefixes should remain consistent across all pages.
Examples:
/ee/blog/
/lv/blog/
/lt/blog/
/ru/blog/
/ee/routes
/lv/routes
/lt/routes
2. Hreflang Implementation (Required)
Add hreflang on all pages.
Example:
<link rel="alternate" hreflang="en" href="https://deliivo.com/en/" />
<link rel="alternate" hreflang="et" href="https://deliivo.com/ee/" />
<link rel="alternate" hreflang="lv" href="https://deliivo.com/lv/" />
<link rel="alternate" hreflang="lt" href="https://deliivo.com/lt/" />
<link rel="alternate" hreflang="ru" href="https://deliivo.com/ru/" />
<link rel="alternate" hreflang="x-default"
href="https://deliivo.com/" />
Important:
/ee → URL
et → hreflang
Every page should include self canonical.
Example:
<link rel="canonical"
href="https://deliivo.com/ee/" />
